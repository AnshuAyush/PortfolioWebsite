## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/yourusername/portfolio.git
cd portfolio
```

### Install Dependencies

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

Application runs at:

```text
http://localhost:5173
```

### Network Access

```bash
npm run dev -- --host
```
